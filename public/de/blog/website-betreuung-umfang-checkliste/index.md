# Was gehört zur laufenden Website-Betreuung?
Canonical URL: https://www.vibeperform.com/de/blog/website-betreuung-umfang-checkliste/
English alternate: https://www.vibeperform.com/en/blog/ongoing-website-support-scope-checklist/
Summary: Inhalte pflegen, Kontaktwege prüfen und Verbesserungen planen: So legen Sie Aufgaben, Zuständigkeiten und Freigaben für Ihre Website-Betreuung fest.

Thema: Website aktuell halten
Datum: 2026-09-30
Autor: Marlon Dietrich
Lesezeit: 3 Min. Lesezeit

Eine Website verändert sich mit dem Betrieb. Neue Leistungen kommen hinzu, Ansprechpartner wechseln und gute Arbeitsbeispiele entstehen. Laufende Betreuung organisiert diese Änderungen: Was soll angepasst werden, wer liefert die Informationen und wer prüft das Ergebnis?

Der Begriff „Website-Betreuung“ allein sagt wenig über den Umfang aus. Inhaltliche Pflege, technische Wartung und Weiterentwicklung sind verschiedene Aufgaben. Halten Sie ausdrücklich fest, welche davon für Ihre Website vereinbart sind.

## 1. Drei Aufgabenbereiche unterscheiden

**Inhaltliche Pflege** umfasst beispielsweise neue Kontaktdaten, überarbeitete Leistungsbeschreibungen, ausgewählte Projektfotos oder geänderte Besuchszeiten. Der Betrieb liefert und bestätigt die Fakten. Die betreuende Person bereitet sie für die vereinbarten Seiten auf.

**Technische Aufgaben** hängen vom verwendeten System ab. Ein System mit Erweiterungen und Datenbank hat andere Wartungsaufgaben als eine statisch erzeugte Website. Klären Sie, wer Hosting, Domain, Updates, Sicherungen und mögliche Störungen betreut. Solche Leistungen sind durch einen allgemeinen Betreuungsbegriff nicht automatisch enthalten.

**Weiterentwicklung** bedeutet, konkrete Verbesserungen zu priorisieren: etwa eine klarere Leistungsseite, ein leichter erreichbares Kontaktformular oder bessere Bildgrößen. Ein größerer Relaunch und zusätzliche Funktionen brauchen eine eigene Abstimmung.

## 2. Den Umfang mit einer Checkliste festlegen

| Frage | Was schriftlich festgehalten werden sollte |
| --- | --- |
| Welche Website wird betreut? | System, Seiten, Sprachen und betroffene Bereiche |
| Welche Änderungen sind enthalten? | Arten der Änderungen, vereinbarter Umfang und Umgang mit Zusatzaufwand |
| Wer liefert Material? | Verantwortliche Person für Fakten, Bilder und gebündelte Rückmeldungen |
| Wer veröffentlicht? | Vorschau, fachliche Freigabe und Zuständigkeit für Veröffentlichung |
| Welche Technik wird betreut? | Konkrete Aufgaben und Zuständigkeiten für Hosting, Domain und Wartung |
| Wie werden Probleme gemeldet? | Kontaktweg und tatsächlich vereinbarte Reaktionszeiten |
| Wie bleibt Arbeit nachvollziehbar? | Kurze Übersicht über erledigte Änderungen und offene Punkte |
| Was passiert bei einer Übergabe? | Zugänge, Unterlagen und vereinbarte Übergabe der Website |

Wenn Sie eine neue [Webseite erstellen](/de/website-erstellen-lassen/) lassen, legen Sie diese Zuständigkeiten am besten schon vor dem Start fest. So ist von Anfang an klar, wer spätere Änderungen übernimmt.

Erforderliche Zugänge sollten für die Aufgabe passend berechtigt sein. Website, Domain und Analysezugänge dürfen bei einer Übergabe nicht nur einer einzelnen externen Person bekannt sein. Klären Sie die tatsächliche Kontoinhaberschaft, bevor Arbeit beginnt.

## 3. Änderungen nach Bedarf einplanen

Ein sinnvoller Pflegeplan folgt den Veränderungen im Betrieb. Neue Kontaktdaten oder falsche Öffnungszeiten brauchen eine andere Priorität als ein zusätzlicher Projektbericht. Legen Sie für jede Aufgabe Anlass, verantwortliche Person und gewünschten Zeitpunkt fest.

Es gibt keine pauschale Pflicht, jede Woche einen Beitrag zu veröffentlichen. [Google empfiehlt hilfreiche, nutzerorientierte Inhalte](https://developers.google.com/search/docs/fundamentals/creating-helpful-content?hl=de). Nutzen Sie echte Kundenfragen und aktuelle Informationen als Anlass; ändern Sie kein Datum allein, um einen unveränderten Text neuer wirken zu lassen.

**Illustratives Beispiel, keine Kundenreferenz:** Ein Elektrofachbetrieb bietet neu eine weitere Leistung an. Der Inhaber bestätigt die Beschreibung und Grenzen. Die Website-Betreuung bereitet die Ergänzung vor, prüft Links und Mobilansicht und zeigt eine Vorschau. Nach Freigabe wird veröffentlicht. Falls die Leistung im Google-Unternehmensprofil erscheint, wird auch dort eine abgestimmte Änderung vorbereitet.

## 4. Wirkung und Funktion angemessen prüfen

Nach Änderungen prüfen Sie zunächst das konkrete Ergebnis: Stimmen die Texte, sind Bilder lesbar und funktioniert der Anfrageweg? Bei Änderungen an Seitenadressen gehören passende Weiterleitungen und interne Links zur Planung.

Wenn passende Analysezugänge vorhanden sind, können Suchanfragen und Nutzung Hinweise auf weitere Verbesserungen geben. Ein Suchranking allein erklärt jedoch weder die Qualität einer Anfrage noch deren Umsatz. Vereinbaren Sie, welche Daten betrachtet werden und welche Aussage daraus tatsächlich möglich ist.

Der [SEO-Startleitfaden von Google](https://developers.google.com/search/docs/fundamentals/seo-starter-guide?hl=de) beschreibt, dass Änderungen unterschiedlich lange brauchen und nicht immer sichtbare Suchauswirkungen haben. Betreuung kann daher keine feste Platzierung oder bestimmte Zahl neuer Anfragen zusagen.

## 5. Mit einer überschaubaren Aufgabenliste beginnen

Sammeln Sie zuerst die heutigen Lücken: falsche Angaben, fehlende Leistungen, defekte Links oder schwer bedienbare Kontaktwege. Ordnen Sie jeder Aufgabe eine zuständige Person und den nächsten Schritt zu. Daraus lässt sich ein passender Betreuungsumfang entwickeln.

Wenn grundlegende Inhalte fehlen, hilft unsere [Inhaltscheckliste für Handwerker-Websites](/de/blog/handwerker-website-inhalte-checkliste/). Für abgestimmte Firmenangaben lesen Sie den [Leitfaden zu Unternehmensprofil und Website](/de/blog/google-unternehmensprofil-website-abgleichen/).
