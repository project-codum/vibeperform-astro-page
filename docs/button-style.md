# VibePerform Button-Stil

Vorgabe von Marlon, 6. November 2026: Buttons sind vollständig abgerundet. Sekundäre Buttons haben immer einen dünnen Rahmen.

Bestehenden Token `--radius-pill` (9999px) verwenden. Primäre Aktionen behalten ihre gefüllte Markenfarbe; sekundäre Aktionen erhalten einen 1px-Rahmen und ausreichend Innenabstand. Dies gilt sprachübergreifend für die gemeinsamen Webseitenkomponenten. Textlinks im Fließtext und anklickbare Projektbilder sind keine CTA-Buttons.

Umgesetzt im lokalen Webseitenstand; nicht veröffentlicht.
